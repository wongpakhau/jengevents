### 1.2 預設處理方式

- **會員碼 = BP 編號**（BP54、BP55…）。這樣商家掃碼或手動輸入時，直接輸入你熟悉的編號。
- **票號由系統自動編**（000001 起）。系統原本的票號是流水號，嘉賓匯入時不支援自訂票號；如果你要保留 BP 編號同時作票號，需要另外加一個小功能（見 1.4）。
- **分組統一設「測試」**，方便日後一次篩選出來刪除。
- **加入方式**：嘉賓管理 → 匯入 CSV，欄位用 `name,phone,member_code,group,note`。可直接用下面這段：

```csv
name,phone,member_code,group,note
adon,66888888,BP54,測試,試驗用戶
Billy,68888888,BP55,測試,試驗用戶
cyrus,68187888,BP62,測試,試驗用戶
David,62755558,BP66,測試,試驗用戶
eva,68908656,BP52,測試,試驗用戶
fanny,68910000,BP27,測試,試驗用戶
```

### 1.3 清理方式

- 現時嘉賓管理是逐筆刪除。**建議加一個「按分組批次刪除」**（只限 owner/admin，需輸入確認字），日後一鍵清走「測試」分組。
- 刪除前系統會提示：已簽到、已有消費紀錄的嘉賓不建議刪除（會影響對帳）。預設：有消費紀錄者禁止刪除，只能標記「停用」。

### 1.4 需要你決定

1. BP 編號只作會員碼（預設），還是同時要作票號？→ 若要作票號，我加一個 `ticket` 匯入欄位（約半天）。
2. 六筆要現在寫入正式資料庫嗎？資料庫是開發與正式共用的，寫入即等於正式資料。

## 2. 簽到、座位、分區（Phase B 基礎）

### 2.1 建議預設

| 項目 | 預設 |
| --- | --- |
| 分區 | VIP 區、A 區、B 區、C 區、工作人員區（可自行改名／加減） |
| 座位格式 | `區-桌-位`，例如 `A-12-3`；容許留空（自由入座） |
| 簽到方式 | 工作人員掃會員 QR，或輸入姓名／電話搜尋後按「簽到」 |
| 重複簽到 | 顯示第一次簽到時間，不重複記錄；可「取消簽到」（需 admin） |
| 簽到憑證 | 嘉賓手機顯示「已簽到」與座位；工作人員畫面同步更新 |
| 座位查詢 | 嘉賓自助頁可查自己的區／桌／位；工作人員可按區／桌列表 |

### 2.2 需要你決定

1. 分區名稱與數量（預設 5 區）。
2. 是否需要「桌號」層級，還是只有區＋座位號？
3. 座位由大會預先編排（匯入），還是現場自由入座、只記錄區？

## 3. 全員禮物抽獎

| 項目 | 預設 |

## 4. 利是抽獎（17:00 HK$1,000、18:00 HK$500）

| 項目 | 預設 |
| --- | --- |
| 17:00 | 抽 1 位，HK$1,000 |
| 18:00 | 抽 1 位，HK$500 |
| 資格 | 該時刻已簽到者 |
| 重複中獎 | 同一場不可重複；兩場可分別人（即 17:00 中獎者仍可參加 18:00） |
| 操作 | 管理員在「抽獎」頁按「抽 17:00 利是」，系統即時抽出並顯示 |
| 記錄 | 得獎人、時間、金額、領取狀態（未領／已領） |

**需要你決定**：17:00 中獎者可否再抽 18:00（預設可以）；未領取如何處理（預設記錄「未領」，可事後補領）。

## 5. 市集消費抽獎（任何人可參加）

| 項目 | 預設 |
| --- | --- |
| 參加資格 | 任何在市集消費的人，包括未預先報名者 |
| 臨時訪客 | 未報名者由商家即場建立「臨時訪客」：姓名＋電話，系統發一個 `V` 開頭訪客碼，可參加抽獎 |
| 抽獎機會 | 每滿 HK$500 得 1 次（可累積；不足 HK$500 不計） |
| 抽獎池 | 現金獎與禮物共用一個池，管理員按「抽獎」隨機抽出 |
| 建議獎品 | 現金 HK$200 × 5、禮物 × 10（可改） |
| 記錄 | 每次抽獎記錄：參加者、消費總額、抽獎時間、獎品、領取狀態 |

**需要你決定**：獎品清單與數量；臨時訪客是否需要大會審批才可參加（預設不需要，商家直接建）。

## 6. 終極大獎（消費最多約 20 人）

| 項目 | 預設 |
| --- | --- |
| 截止時間 | 19:30（拍賣開始前），截止後新增消費不計入排名 |
| 名額 | 固定 20 人（可設 10–30） |
| 排名依據 | 已確認（買家確認）的消費總額；不含已取消 |
| 同額處理 | 最後一筆消費時間較早者優先 |
| 資格 | 必須已簽到；工作人員與商戶帳戶不列入 |
| 抽獎 | 管理員在 20 人名單按「抽終極大獎」→ 隨機 1 位 |
| 顯示 | 大屏可顯示 20 人名單與金額（電話可隱藏，只顯示姓名＋會員碼） |
| 記錄 | 名單快照、抽出結果、領取狀態 |

**需要你決定**：截止時間（19:30？）、固定 20 人還是可設定、是否公開名單與金額。

## 7. 拍賣

| 項目 | 預設 |
| --- | --- |
| 拍賣品 | 管理員逐件建立：名稱、圖片、起標價、加價幅度、時限 |
| 起標價 | 每件自訂，預設 HK$500 |
| 加價幅度 | 每件自訂，預設 HK$50；用戶介面有「+HK$50」「+HK$100」「自訂出價」 |
| 時限 | 每件 3 分鐘；最後 30 秒有人出價自動延長 30 秒（防最後一秒搶標） |
| 結束 | 倒數完結自動結束；管理員可隨時「結束這件」 |
| 資格 | 已簽到者；預設不需先登記付款方式 |
| 出價顯示 | 即時最高價、出價者姓名＋會員碼後 4 位 |
| 保留價 | 預設不設；如設，未達保留價則流標 |
| 得標後 | 記錄「待收款」；管理員可標記「已收款」或「取消得標」 |
| 用戶介面 | 手機看到目前拍賣品、現價、剩餘時間、出價按鈕、我的出價狀態 |
| 管理員介面 | 建立／開始／暫停／結束、即時出價紀錄、得標名單 |

**需要你決定**：起標價與加價幅度、時限長度、是否需要保留價、得標後付款方式（現場現金／轉帳／待定）。
