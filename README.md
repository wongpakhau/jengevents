# EventFlow MVP

香港白牌活動管理平台。本版已從v0接通真實OAuth、MySQL持久資料及三端操作，不再以虛構活動作營運畫面。使用者於2026-10-30授權完成MVP；未公開發布，未灌入示範嘉賓、消費或得獎資料。

## 已接通

大會建立組織及活動、嘉賓新增／編輯／CSV匯入／邀請QR、公開登記與私隱同意、相機／人工QR簽到；12人圍枱嘉賓拖放及枱位置保存；商戶金額輸入、單次消費憑證QR、嘉賓身份接續後自動領取及權益顯示；10%有效交易應收、手動已收款、作廢、會計CSV；owner/admin/checkin/draw/merchant角色邀請及撤銷；白牌名稱／Logo／主色／規則保存及新活動複製；後端安全加權抽選與獨立約7秒普通三軸舞台。無柏青哥擦邊、反轉、重轉或演出機率。

商戶與工作人員必須真實OAuth登入，嘉賓以不可猜測個人邀請憑證識別，消費QR不是身份。原始token只在發出時回傳，資料庫存hash，冪等回覆以AES-GCM加密。所有業務變更在MySQL活動列鎖交易內完成，畫面或localStorage不是帳本權威。

預設每筆HK$1,000一次，HK$2,300及HK$2,500均2次；可按規則版本跨筆累積。10%逐筆half-up至分。交易保留當時門檻和累積方式；後改設定不重算舊交易。作廢保留原紀錄與原因，不計入新應收；已入抽獎快照者保留歷史例外，不納入未來新抽獎。已收多於應收時顯示負餘額，不自動退款或扣款。CSV交易與收款獨立列，收款只出現一次，含原費用／作廢調整／有效應收並防試算表公式注入。

活動複製不帶嘉賓、憑證、收款、帳本、得獎或原有工作人員。組織擁有人仍是新活動owner；若由已授權admin建立副本，給該建立者獨立admin權限，不提升為owner。

## 使用與操作

詳見 [操作指南](operator-guide.md)。登入後建立首個空白活動；嘉賓、商戶及抽獎各頁均讀寫真實資料。大屏幕須登入且有抽獎角色，在控制台開始抽獎後自動播放，重播只重播同一結果。六位票號前三位固定明示，後三位捲動，支援超過999位嘉賓。

## 指令及資料庫

- `pnpm db:migrate`：執行現有Drizzle遷移，包含已實際成功套用的 `0001_eventflow.sql`（只新增ef_資料表，保留users）。
- `pnpm check`：TypeScript；`pnpm test`：單元／回歸測試；`pnpm build`：前後端編譯。
- 預覽須先宣告Session端口，再 `HOST=127.0.0.1 PORT=<Session端口> pnpm dev`。正式容器保留PORT及0.0.0.0預設，健康端點 `/api/health`。本次端口3000，不變更8328 gateway。

業務連線保留DATABASE_URL的TLS選項，不關閉憑證校驗。MVP以MySQL持久JSON活動聚合+SELECT FOR UPDATE序列化寫入；所有授權、交易、權益及快照由後端驗證。大型高併發前需要負載測試，必要時分拆正規化業務表，不宣稱已達大型活動承載驗收。

## 驗證範圍

已完成類型、單元與回歸測試、編譯、實際MySQL新增遷移及未授權／未知活動HTTP防護檢查；詳見development-notes.md及mvp-review.md。未代替用戶進行真人OAuth的整套營運操作，未做手機相機、投影機、場地網絡或高併發驗收。正式香港消費抽獎牌照及個人資料告知仍須大會確認。不自動付款、不寄發實際邀請、不公開發布。

Logo接受持久HTTPS或 `/manus-storage/...` 平台資產路徑；不接受虛構manus-storage://協議、data:或任意相對路徑。站內預設小型SVG保留；平台metadata持久HTTPS logoUrl未配置，不影響站內白牌Logo保存。
